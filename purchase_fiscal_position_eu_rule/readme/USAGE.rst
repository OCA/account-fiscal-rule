Once installed, fiscal position resolution on purchase orders automatically
uses the full vendor + buyer + delivery address triplet.

No manual action is required. The correction applies to all purchase orders
created or recomputed after installation.

For the correction to also apply to sale orders and standalone invoices, install
the companion modules:

- ``sale_fiscal_position_eu_rule`` — for sale orders
- ``account_move_fiscal_position_eu_rule`` — for standalone invoices
